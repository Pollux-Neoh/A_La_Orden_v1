# A la Orden

Aplicación de pre-pedidos para restaurantes que permite a los usuarios explorar restaurantes cercanos, armar su pedido, pagarlo y recogerlo mediante código QR, optimizando los tiempos de atención y reduciendo el impacto de las horas pico.
